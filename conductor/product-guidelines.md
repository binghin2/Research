# Product Guidelines

## Prose Style
- **Technical and Formal:** Maintain an objective, precise, and structured tone in all research reports, notebook annotations, and documentation.
- **Academic Precision:** Use clear and unambiguous terminology related to physiological signals and machine learning.
- **Conciseness:** Prioritize high-signal-to-noise communication, focusing on methodology and results.

## Visual and UI Principles
- **Academic/Minimalist Visualization:** Prioritize clarity and high-contrast in all charts and graphs, ensuring they are suitable for academic publication.
- **Standardized Labeling:** Ensure all axes, legends, and titles are clearly labeled using standardized units and terminology.
- **Consistency:** Maintain a consistent color palette and font style across all data visualizations to facilitate comparison.

## Documentation Standards
- **Standardized Docstrings:** Follow NumPy or Google style docstrings for all Python modules, classes, and functions to ensure maintainability and readability.
- **Inter-cell Documentation:** Use Markdown cells in Jupyter Notebooks to provide high-level context and explain the rationale behind specific data transformations or model choices.
- **Metadata Tracking:** Document key experimental parameters (e.g., hyperparameters, dataset versions) within the notebooks or as separate metadata files.

## Development Workflow
- **Granular Progress:** Commit changes frequently with descriptive messages that clearly reflect the research step or experimental modification.
- **Reproducibility:** Prioritize code and environment reproducibility, including clear lists of dependencies and data sources.
- **Validation-First:** Always validate data integrity and model performance using standardized metrics before finalizing any research phase.
