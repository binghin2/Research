# Technology Stack

## Core Language
- **Python 3.x:** Primary language for all data processing, model development, and experimentation, implemented through Jupyter Notebooks.

## Machine Learning & Deep Learning
- **PyTorch:** Used for implementing and training sophisticated deep learning models (e.g., LSTM, GRU, Transformer, CNN-Transformer) for multi-modal signal classification.
- **scikit-learn:** Utilized for traditional machine learning algorithms, model evaluation metrics, and dataset splitting.

## Data Processing & Analysis
- **pandas:** For efficient data manipulation, cleaning, and structured dataset management.
- **numpy:** For high-performance numerical computations and array-based operations.
- **scipy:** For signal processing tasks and statistical analysis of physiological data.

## Data Visualization
- **matplotlib:** Foundation for all static data visualizations and academic-style charts.
- **seaborn:** Used for advanced statistical data visualization and trend analysis.

## Project Format
- **Jupyter Notebooks (.ipynb):** The primary environment for research experimentation, analysis, and documentation.
- **Trained Models (.pth, .joblib):** Standardized formats for exporting and storing trained model weights and preprocessing objects.
