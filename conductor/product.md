# Initial Concept
Research and development of machine learning models for estimating Flow (Immersion), Concentration, and Fatigue using multi-modal physiological data.

# Product Definition

## Vision
To develop high-accuracy machine learning models for estimating Flow (Immersion), Concentration, and Fatigue using multi-modal physiological data, specifically targeting the research community.

## Core Features
- **Multi-modal Physiological Signal Classification:** Implementing and refining models for accurate estimation of Flow, Concentration, and Fatigue from multi-modal signals including EDA, BP, HRV, HR, EMG, and SKT.
- **Data Preprocessing Pipelines:** Developing efficient pipelines for cleaning, scaling, and feature extraction from diverse physiological datasets.
- **Model Evaluation and Comparison:** Providing tools and notebooks for accuracy comparison across different model architectures (e.g., LSTM, Transformer, CNN-Transformer) and signal modalities.
- **Visualization and Trend Analysis:** Tools for visualizing physiological trends and model prediction results to gain deeper research insights.

## Target Users
- **Researchers:** Those advancing AI techniques in affective computing and physiological signal analysis.

## Research Goals
- **Model Accuracy:** Achieving the highest possible F1-score and accuracy across all classification tasks.

## Deliverables
- **Preprocessed Datasets:** Cleaned and structured multi-modal physiological datasets ready for model training and evaluation.
- **Evaluation Reports:** Comprehensive performance analysis reports including metrics (Accuracy, F1-score) and Confusion Matrices for compared models (LSTM, Transformer, etc.).
- **Visualization Modules:** Functional code modules for visualizing sensor data trends and model prediction results.
